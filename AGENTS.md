# Работа над Keenetic Pilot

Проект и все изменения находятся в `punisher89/my.kn-test-`. Пользователь
хочет самостоятельную реализацию. z2k, zapret2-z2k и d2p служат источниками
идей и сведений о методах; их репозитории не изменять.

Своя часть — панель, API, контроллер, настройки, подбор, установка и служба.
nfqws2 — явно указанная внешняя зависимость с закреплённой версией и SHA-256.
Не выдавать её движок за свою разработку. Не запускать установщики других
проектов и не использовать их конфигурацию как конфигурацию Pilot.

Сохранять ключи, настройки, списки и отчёты пользователя при обновлении.
Изменять только собственные правила firewall. Не отключать проверку TLS,
контрольных сумм или содержательные проверки ради успешного теста.

Полная локальная проверка на Linux amd64: `sh scripts/check.sh`.
Для выбранного Go используйте переменную `GO`; для готового закреплённого
архива движка — `PILOT_ENGINE_ARCHIVE`. Архив всё равно проверяется по SHA-256.
Рабочие файлы `local/`, `.cache/`, `build/` и `dist/` исключены из Git.

Первый реальный стенд: KN-1811, Entware на USB, Ростелеком, YouTube, Discord
и webOS с TLS 1.2. Отличать нативный dry-run, модель firewall, проверку TLS
и испытание на роутере. Проба сайта не подтверждает видео/голос; проба TLS 1.2
не эмулирует ClientHello webOS. Не называть аппаратные сценарии проверенными
без результатов с устройства. Макеты должны явно обозначать примерные данные.
