# alpha.30 [ChatGPT]

Поиск одного метода теперь без копирования каталога и вычисления семейства всех стратегий. Приоритет домена кэшируется в пределах одного тика планировщика; новый тик читает новую конфигурацию. Фоновый планировщик извлекает TLS/IP без создания и хеширования объекта коробки. Поведение методов, лимиты, firewall, проверка TLS и подписанный канал не меняются. Тесты сравнивают результаты и проверяют нулевые выделения при lookup; бенчмарк сравнивает старый и новый путь. Снижение CPU на KN-1811 не измерено.
