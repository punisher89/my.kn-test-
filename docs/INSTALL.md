# Быстрая установка Keenetic Pilot

Для KN-1811 с Entware на USB. Нужны установленный Entware и компонент
KeeneticOS «Модули ядра подсистемы Netfilter». Если z2k/D2K уже работают,
остановите их перед включением обхода Pilot. Их файлы установщик не меняет.

## 1. Вставьте одну команду в SSH Entware

Это Linux-оболочка Entware от root, не командная строка Keenetic `ndmc`.
Если `opkg` не распознаётся, проверьте, что подключились к SSH Entware.

```sh
opkg update && opkg install curl ca-bundle && curl -fsSL https://raw.githubusercontent.com/punisher89/my.kn-test-/refs/heads/feature/keenetic-pilot/install.sh -o /tmp/keenetic-pilot-install.sh && sh /tmp/keenetic-pilot-install.sh
```

Не нужно скачивать артефакты Actions, выбирать ARM64 вручную или ставить Go.
Установщик получает готовый пакет из ветки `packages` этого репозитория,
проверяет закреплённую сумму манифеста и сумму архива. Движок nfqws2 скачивается
отдельно с обязательной проверкой своей закреплённой суммы. TLS не отключается.

## 2. Откройте адрес из результата установки

В конце SSH покажет, например:

```text
Панель: http://192.168.1.1:9080
Код первого входа (15 минут): <восемь цифр>
```

Адрес определяется по интерфейсам роутера. При занятом порте выбирается
свободный из 9080–9090. Телефон/ПК должны находиться в домашней сети этого
Keenetic. Первую настройку выполняйте из основной домашней сети.

Введите код из SSH и придумайте пароль длиной от 10 символов. Дальше вход —
по этому паролю. Длинный ключ из файла читать и копировать не требуется.
Пароль хранится как PBKDF2-хеш с солью; сеанс использует HttpOnly-cookie.

Если код истёк, получите новый:

```sh
/opt/keenetic-pilot/bin/pilot --pair
```

Код нельзя использовать, чтобы перезаписать уже заданный пароль.

## 3. Включите обход в панели

Нажмите **«Настроить подключение»**. Подключение провайдера выбирается по
маршруту роутера; при необходимости его можно заменить в списке.
Нажмите **«Сохранить и включить обход»**. По умолчанию сразу начнётся подбор
YouTube. Discord можно подобрать отдельно в «Сервисах и доменах».

Контроллер и панель запускаются сразу после установки. При первой установке
перехват включается вашим действием в панели; обновление сохраняет прежнее
состояние обхода. Если Netfilter недоступен,
панель остаётся работающей и показывает ошибку запуска движка.

## Если панель не открывается

Сначала проверьте точный адрес, напечатанный установщиком, и подключение
телефона/ПК к домашней сети. Затем в SSH:

```sh
/opt/etc/init.d/S98keenetic-pilot status
/opt/etc/init.d/S98keenetic-pilot restart
/opt/keenetic-pilot/bin/pilot --panel-info
```

Журнал ошибок запуска: `/opt/var/log/keenetic-pilot.log`.
При неоднозначной сети можно явно передать адрес в простую установку:

```sh
sh /tmp/keenetic-pilot-install.sh --listen 192.168.1.1:9080
```

Замените IP на настоящий LAN-адрес. Для намеренной установки только через
SSH-туннель используйте распакованный пакет с `--listen 127.0.0.1:9080`
без `--lan-panel`. LAN-панель работает по HTTP; на недоверенной сети используйте
SSH-туннель или локальный HTTPS-прокси.

## Обновление, остановка и удаление

Обновление — та же одна команда из шага 1. Пароль, ключ API, списки и
результаты сохраняются. Перед заменой проверяются все загрузки. При ошибке
обновления установщик пытается восстановить старое приложение и настройки;
ошибка восстановления не скрывается.

```sh
/opt/etc/init.d/S98keenetic-pilot stop
sh /opt/keenetic-pilot/scripts/uninstall.sh
```

Удаляются приложение, init-скрипт и хук Pilot. Конфигурация и пароль в
`/opt/etc/keenetic-pilot`, журналы и резервные копии сохраняются. Зависимости
Entware и файлы других проектов не удаляются. Не удаляйте `firewall.json`:
он нужен для аварийной очистки собственных правил и восстановления sysctl.

## Что ещё проверяется на роутере

Версия alpha. Локально проверены установка, обновление, вход по паролю,
работа HTTP-панели и её настройка. Реальную обработку пакетов NFQUEUE/PPE,
видео YouTube/webOS и голос Discord необходимо испытать на KN-1811 в вашей
сети. HTTPS-проба TLS 1.2 не эмулирует ClientHello телевизора и не подтверждает
воспроизведение видео. QUIC и Discord UDP пока используют статические стратегии.
