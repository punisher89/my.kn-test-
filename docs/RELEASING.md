# Подготовка устанавливаемой версии

Готовые контроллеры публикуются в отдельной ветке `packages` этого же
`punisher89/my.kn-test-`. Для получения файлов установщик использует обычный
HTTPS без GitHub API или входа в Actions. Исходная ветка содержит `install.sh`
с закреплённым SHA-256 манифеста конкретной версии.

1. Измените `VERSION` на новую alpha-версию.
2. Выполните `sh scripts/check.sh`. Проверяются все архитектуры, контрольные
   суммы, пароль/сеанс и жизненный цикл реальной службы в тестовом каталоге.
   Тест загрузки установщика использует подмену транспорта с настоящими пакетами;
   он не доказывает доступность GitHub.
3. Не пересобирая проверенные архивы, выполните:

   ```sh
   python3 scripts/publish-packages.py --push --update-installer
   ```

4. Проверьте доступность опубликованных файлов по HTTPS и совпадение сумм.
5. Закоммитьте и отправьте исходники вместе с обновлённым `install.sh`.

Скрипт публикации использует временный Git index, не создаёт worktree,
не переключает исходную ветку и не меняет рабочие файлы других проектов.
Используется Git-аутентификация текущего репозитория; новый токен API не нужен.
При существующей версии с другими байтами публикация отказывается продолжать:
нужно повысить версию. Старые выпуски сохраняются; force push не используется.

Обычный `scripts/check.sh` готовит пробный установщик в `.cache/installer/`
и не изменяет закреплённые суммы исходного `install.sh`.
