# Каталог популярных сервисов

В каталоге девять сервисов, включая Telegram Web. Это готовые
профили доменов и HTTPS-проверок, а не список гарантированно заблокированных
или гарантированно работающих ресурсов. Доступность зависит от сети и сервиса.

| Сервис | Основные домены | Контрольный адрес |
| --- | --- | --- |
| YouTube | youtube.com, googlevideo.com, ytimg.com и связанные | Сохранённые проверки YouTube и изображения |
| Discord | discord.com, discord.gg, discord.media и связанные | HTTPS gateway API |
| Instagram | instagram.com, cdninstagram.com | www.instagram.com/robots.txt |
| Facebook | facebook.com, fbcdn.net, fb.com | www.facebook.com/robots.txt |
| X / Twitter | x.com, twitter.com, twimg.com, t.co | x.com/robots.txt |
| ChatGPT | chatgpt.com, openai.com, oaistatic.com, oaiusercontent.com | chatgpt.com/robots.txt |
| WhatsApp Web | whatsapp.com, whatsapp.net, wa.me | www.whatsapp.com/robots.txt |
| Signal | signal.org, signal.art, signal.group, signal.link | signal.org/ |
| Telegram Web | telegram.org, t.me, telegram.me, telegra.ph, telesco.pe | telegram.org/ |

Полный набор находится в `internal/pilot/service-presets.json` и доступен
в раскрываемых подробностях каталога панели. У существующих профилей адреса,
домены и выбранные стратегии не меняются при обновлении или добавлении других
сервисов. Если пользователь изменил YouTube или Discord, каталог их не заменяет.

В «Сервисах и доменах» добавьте профиль, затем раскройте его строку, чтобы
изменить стратегию, домены и проверки. В «Подборе стратегий» добавленный профиль
сразу выбирается в списке; запуск подбора требует отдельного нажатия. Простое
добавление не объявляет профиль рабочим и не запускает сетевые проверки.
Работающий движок перезапускается для применения изменённой области обработки.

Новый профиль использует `none` («Без вмешательства»). Автоподбор по трафику,
если включён, сможет менять метод при наблюдаемых повторных сбоях. Плановая
проверка действует согласно общим настройкам. Ручное закрепление/пауза имеют
обычный приоритет. Не допускаются пересекающиеся домены между профилями;
каталог помечает занятые домены. Общий предел — 12 подключённых профилей.
Удаление последнего профиля запрещено. При удалении профиля обучение и ручные
правила сохраняются, в том числе независимые закрепления его доменов.

## Что подтверждает проверка

У новых профилей требуется HTTP 200 и контрольный текст: `User-agent` у
`robots.txt` или `Signal` у сайта Signal. Проверяются сертификат и TLS 1.2/1.3;
редиректы остаются под существующим контролем HTTPS-проб. Ответы 403/451,
страницы блокировки и ошибки TLS не считаются успехом по умолчанию.

Контрольный `robots.txt` помогает проверить HTTPS-доступ к указанному адресу.
Он не подтверждает вход, сообщения, ленту, API приложения, видео или звонки.
Настройка Signal проверяет сайт, а не протокол приложения. WhatsApp Web не
включает проверку звонков. ChatGPT может ограничивать доступ по региону или
аккаунту; подбор DPI-метода сам по себе таких ограничений не снимает.
Результаты проверок из среды разработки не являются испытанием у российского
провайдера. На роутере проверяйте нужный сценарий отдельно.

Можно изменить контрольный адрес, ожидаемый код и фрагмент ответа в профиле.
Выбирайте содержательный ответ именно нужного сценария, а не ослабляйте проверки
ради формального успеха. Домены нового адреса должны входить в этот профиль.

API: каталог включён в авторизованный `GET /api/status` как `service_presets`;
добавление — `POST /api/services` с `{"id":"instagram"}`, удаление —
`DELETE /api/services/instagram`. Действуют обычные проверки доступа, Origin,
блокировка операций, проверка полной конфигурации и откат при ошибке применения.


## Свой сервис

В «Сервисах и доменах» раскройте «Добавить свой сервис». Укажите название,
контрольный HTTPS URL и фрагмент ожидаемого ответа. Код проверки по умолчанию
200; затем адреса и код можно отредактировать в профиле. Пустой фрагмент при
создании своего сервиса не принимается. При пустом списке доменов используется
хост контрольного адреса. ID создаётся автоматически, новый метод — `none`.

## Домены из интернета

Источник настраивается в раскрытом профиле. Встроенные сервисы могут использовать
собственный подписанный `catalog/domains.json` Pilot. Свои сервисы — публичную
HTTPS-ссылку без логина, порта, query-параметров и фрагмента. Ссылка должна вести
на текстовый список: один домен на строку, `#` для комментариев. Допустимы
`*.example.com` и `domain:example.com`, означающие корневой домен с поддоменами.
IP/hosts-файлы, Adblock-правила, исполняемый код и HTML не принимаются.

Проверяются сертификат, публичность DNS-адресов, перенаправления, размер
до 128 КиБ и до 300 уникальных доменов. Соединение использует проверенный
IP без второго DNS-разрешения. GitHub-токен не отправляется сторонним источникам.
Для своего HTTPS-источника доверие определяется выбранным URL и TLS; можно
дополнительно закрепить SHA-256. Изменившийся файл при закреплённой сумме
не применяется до изменения суммы пользователем. Встроенный каталог отдельно
проверяется Ed25519-ключом обновлений и номером ревизии.

При загрузке охват существующих доменов сохраняется. Уже покрытые поддомены
не дублируются; новый родительский домен заменяет вложенные записи без потери
их охвата. Изменения полностью проверяются на пересечения с другими профилями
и соответствие контрольным адресам перед применением. При конфликте список
остаётся прежним. Новые домены перезапускают работающий движок с обычным откатом;
при неизменном охвате обновляется только время, без перезапуска.

«Не добавлять из источника» блокирует также родительские домены, которые
охватили бы исключённый поддомен. Это исключение импорта; уже заданные ручные
домены оно не отключает. Для удаления уберите домен из профиля и исключите
его повторный импорт либо выключите автообновление. Удаление доменов из
источника само по себе не удаляет их из профиля.

Автообновление выполняется раз в сутки; после запуска первая попытка — в
цикле контроллера примерно через 30 секунд. Подписанный каталог кэшируется
на минуту, включая ошибки, чтобы несколько профилей не повторяли один
неудачный запрос. Ручная кнопка «Сохранить и загрузить домены» применяет
введённые настройки, затем пробует импорт. При недоступном источнике сохранённые
домены продолжают работать. Старые профили при обновлении приложения сохраняют
ручной режим; источник и автоматизацию можно включить отдельно.

Telegram Web не включает MTProto и звонки приложения. Загрузка доменов не
превращает HTTPS-стратегии в обработчик MTProto и не доказывает работу Telegram.

Дополнительные API: `POST /api/services/custom` принимает профиль с контрольным
фрагментом; `POST /api/services/{id}/domains` импортирует домены из сохранённого
источника. На каждое изменение действуют авторизация, Origin, блокировка
операций, проверка полной конфигурации и прежний механизм отката.
