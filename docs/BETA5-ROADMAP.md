# Beta.5 — разработка, не опубликованный выпуск

База beta.4. Текущий движок nfqws2 и каналы обновления ChatGPT/Codex сохраняются. Перед выпуском — полный CI, тестирование на ARM64 и MIPSEL, проверка отката. Не публиковать личные отчёты, ключи и токены.

- [x] Диагностический экспорт: диапазоны событий за час, сутки и неделю, отдельно от накопленных попыток; фиксированные коды состояния службы, хранилища, старых наблюдений и активного поиска.
- [x] Написаны модульные тесты для счётчиков и диагностических кодов; запуск CI требуется.
- [x] Добавлена кнопка самодиагностики и отображение диапазонов истории в панели; требуется браузерная проверка.
- [x] Закрытие музыкального меню и оформления по клику снаружи или Esc, сворачивание окна обновления без отмены установки; добавлены браузерные тесты.
- [x] Описание установленной версии отдельным блоком; состояние раскрытия сохраняется при опросе; браузерные тесты добавлены.
- [ ] Очистка истории: отдельная операция с резервной копией и согласованием с писателем состояния; не удалять обучение, закрепления, исключения. Настраиваемое хранение, без автоматического удаления по умолчанию.
- [ ] Автоподбор: устранить проблемы актуальности наблюдений и повторных событий, приоритет подтверждённого опыта; проверить причину client_hello_missing.
- [ ] Самодиагностика DNS, маршрутизации, конфликтующих служб, ресурсов без автоматического вмешательства.
- [ ] VPN-подписки: ограниченная загрузка с проверкой TLS, импорт после подтверждения, проверка сервера, отдельное хранение секретов. Не применять маршруты автоматически.
- [ ] MIPS: облегчённый режим фоновых задач, измерение CPU/RAM и испытания на Giga.
- [ ] Резервное копирование и восстановление: проверка формата, версии, прав и целостности, предварительный просмотр, сохранение обучения.
- [ ] Откат обновления: локальный резерв рабочего пакета, независимые проверки сети и службы, ограничение повторов, ручное восстановление. Не откатывать по единичному внешнему сбою.
- [ ] Центр уведомлений: ошибки, обновления, диагностика, дедупликация, ограниченная история.
- [ ] Pilot Engine на Rust: отдельная экспериментальная ветка, синтетические тесты и сравнение ресурсов; не заменять рабочий движок без испытаний.

## Дополнительная реализация
- Очистка истории вручную с остановкой писателя, резервированием исходных слотов и сохранением текущих наблюдений. Автоочистка по сроку пока отсутствует.
- Облегчённый режим: опрос очереди каждые 30 секунд, задержка повторов при отсутствии ClientHello увеличена. Измерения на MIPS ещё не проведены.
- Экспорт и восстановление конфигурации с SHA-256 (контроль повреждения, не подпись), сохранением локальных путей и каталога. Восстановление обучения отдельной операцией ещё не реализовано.
- Центр уведомлений текущего сеанса в журнале, не постоянное серверное хранилище.

- VPN-подписки: HTTPS-загрузка с публичного IPv4, без редиректов, лимит 512 КиБ, предпросмотр типов URI/plain/base64 без ключей. Нет сохранения, расписания обновлений, проверки подключения к серверу и применения профиля; это первый этап.

- Импорт одной подписки, ручное обновление с сохранением прежней при ошибке и удаление; данные и адрес хранятся отдельно с правами 0600, API выдаёт только сводку. Автоматическое обновление по расписанию, запуск клиентов и проверка конкретных серверов остаются отдельными задачами.

- Ручная очистка сохраняет последние 10 минут событий для ранжирования. Добавлено восстановление наблюдений/истории из собственной локальной копии (без замены текущего конфига, списка обнаруженных доменов и отдельных подтверждённых планов). Автоочистка по сроку 1–365 суток в Lua при активности, по умолчанию отключена; смешанные группы сохраняются по последнему событию. Проверки необходимы.

- Установщик beta.5: проверка состояния службы после запуска и защитный откат при двукратном полном отказе двух независимых HTTPS-адресов, если оба были доступны до обновления. Использует существующий механизм восстановления приложения, не меняет подписанный или Codex worker. Проверяет доступность с роутера, не измеряет скорость и не гарантирует доступность клиентских устройств. На стенде ещё не испытано.

- Автообновление ранее импортированной подписки раз в сутки (настройка выключена по умолчанию); при сетевой ошибке остаются прежние данные. Учитывается пауза фоновых задач и блокировка операций.
