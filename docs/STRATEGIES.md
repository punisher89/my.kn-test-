# Стратегии и автоматический подбор

## Автоподбор по трафику

В версии `0.2.0-alpha.1` появился отдельный режим **Настройки → Автоподбор по
трафику**. После сохранения настройки движок наблюдает первые пакеты HTTPS.
Новый сайт с видимым SNI на TCP/443 начинает без вмешательства; домены готовых
профилей — с выбранного вами метода (также на дополнительных HTTPS-портах профиля).
После двух неудачных соединений за 60 секунд выбирается следующий вариант.
Признаки сбоя: ранний входящий RST, повторная передача ClientHello, ранний
фатальный TLS alert, видимый до шифрования в TLS 1.2. Новая стратегия действует
для **следующего соединения**: повторите открытие сайта или запуск приложения.
Если подходящего метода нет, перебор идёт по кругу; обещать обход любой блокировки нельзя.

Домен, версия ClientHello (TLS 1.2 / предложение TLS 1.3) и семейство IP имеют
независимый выбор. Так сбои телевизора не меняют метод ПК с TLS 1.3. Если
ClientHello не удалось полностью разобрать, используется отдельная группа
«TLS не определён». Протокол TLS не понижается. Состояние по умолчанию находится
в `/opt/keenetic-pilot-state`, до 512 наблюдений и 1000 обнаруженных доменов.
Новые сайты, успешно работающие без вмешательства, туда не добавляются.
Данные сохраняются при обновлении и обычном удалении приложения.

На странице **«Коробки обхода»** показаны выбранные методы. «Пробуется» означает
смену после сбоев; «Есть ответ» — передачу данных сверх порога наблюдения.
Этот признак не проверяет сертификат или содержимое ответа. Активный подбор
сервиса по-прежнему выполняет полноценные HTTPS-проверки TLS 1.2/1.3, затем
подтверждение после перезапуска и откат при неудаче. На время такого подбора
пассивная ротация отключается, чтобы не исказить результат.

Режим выключен по умолчанию для сохранения работающих настроек. Включённые
исключения действуют и здесь. Сбои Wi-Fi/сервера могут выглядеть как блокировка.
ECH, скрытый SNI, блокировка IP и DNS не решаются этим детектором. Обычный HTTP,
QUIC и голос Discord не получают автоматический подбор: их прежние правила
сохранены. На роутере проверяйте HTTPS и реальное видео/звонки отдельно.

Автообход использует поставляемый с движком API `circular` и стандартные
детекторы nfqws2. Наш Lua-контроллер добавляет независимые TLS/IP-группы,
ограниченное хранение, восстановление выбранных методов и наблюдения для панели.
Каталог не содержит исполняемый Lua. Файлы Lua остаются доступны только для чтения;
UID движка может писать только в заранее созданные файлы состояния.

## Коробки и повторное использование опыта

С `0.2.0-alpha.2` страница «Коробки обхода» группирует наблюдения по TLS,
IP-семейству, WAN, порту и признаку сбоя: RST, повторные передачи, ранний TLS
alert либо неизвестный признак. Сходство этих признаков — основание проверить
кандидата, а не доказательство одинаковой DPI-системы. Карточка показывает
домены, семейства найденных методов, происхождение выбора и историю попыток.

Настройка «Использовать опыт коробок» включена по умолчанию; при выключенном
автоподборе она не запускает обработку трафика. Сначала новый сайт использует
обычное соединение, готовый профиль — выбранный метод. Только после двух
сбоев очередь получает до трёх методов с ответами других доменов за последние
семь дней, при совпадении всех условий контекста. Кандидаты упорядочиваются по
числу разных доменов с ответами, затем свежести. Успех другого домена не считается
успехом нового. Если кандидаты не помогли, продолжается остальной набор без
повторного прохода уже предложенных методов до завершения круга.

Известные ошибки и более новые наблюдения заменяют старый успех для того же
домена и контекста. Устаревшие данные, неизвестный TLS/признак/подключение/порт,
отсутствующий в текущем наборе метод и обычное соединение не служат донорами.
При повторном наблюдении ответа срок опыта обновляется не чаще раза в час,
чтобы сократить запись на USB. Переиспользование можно отключить отдельно.

Состояние переходит с рамок `PILOT1` на `PILOT2`, сохраняя выбранные методы.
Прежний формат читается; до записи нового полного кадра остаётся предыдущий
завершённый слот. В двух файлах ограничены 512 текущих записей и 128 записей
истории, до 512 КиБ на слот. Старые записи без контекста показываются отдельно
и не используются для выбора метода другого сайта. После перехода старые версии,
читающие только `PILOT1`, не смогут прочитать новые кадры опыта.

В «Каталоге методов» доступна группировка по действию, включая загружаемые
совместимые варианты. Она упорядочивает список выбора, не ограничивая набор
кандидатов для обхода.

## Свежесть наблюдений в панели

Порог отображения — сутки с момента `updated`. После него текущий результат
показывается как «Нет свежих наблюдений», без объявления метода нерабочим.
Исключения, новые закрепления и действующие ограничения смен показываются
отдельно. Записи с неполным или прежним контекстом подключения отмечены как
сохранённые наблюдения.

Коробка остаётся в основном списке, пока в ней есть наблюдение или событие
за последние сутки с актуальным WAN и известным портом. Остальные коробки
показываются в свёрнутом разделе «Сохранённый опыт и история». При выборе
поиска или фильтра найденные сохранённые коробки раскрываются. В фильтр
«Пробуется» старые неподтверждённые записи больше не включаются; для них есть
фильтр «Нет свежих наблюдений».

Это только представление сохранённых данных. Срок свежести не участвует
в Lua-ротации и не удаляет метод. При новом трафике движок использует
совместимый сохранённый метод и продолжает наблюдение/подбор при сбоях.
Отдельных фоновых запросов к неиспользуемым сайтам нет. Опыт, пригодный для
других доменов, по-прежнему оценивается по прежним условиям и семидневному окну.

Повторяющиеся исходы в истории панели объединяются по домену, группе,
подключению, порту, методу, статусу, признаку и источнику до следующего
изменения состояния этого контекста. События других доменов могут идти между
ними; они не теряются. У отложенных смен учитываются причина и срок паузы.
Панель показывает число событий и время первого/последнего в группе.
Начиная с `0.2.0-alpha.9`, повторные **ошибки** объединяются и при записи.
Сопоставление требует совпадения домена, группы, WAN, порта, метода, признака,
источника и записанного ограничения. Любое следующее событие другого статуса
этого контекста разрывает объединение. События смены метода, успеха и задержки
не объединяются в хранилище. При переводе часов назад начинается новая запись.
Счётчик ограничен миллиардом событий на запись. Группа перемещается в конец
истории по последнему событию; сохраняются до 128 записей и прежний предел
размера файла. Запись на USB по-прежнему ограничена прежним интервалом.

`PILOT4` добавляет `event_count` и `first_updated`. Старые форматы 1–3 читаются;
повторные ошибки старой истории уплотняются движком при загрузке и сохраняются
при следующей записи. Выбранные методы не сбрасываются. Старые приложения,
не поддерживающие `PILOT4`, не читают новые кадры; обратная совместимость
обеспечена для обновления, а не для понижения версии.

## Ручные правила и защита от частых смен

С `0.2.0-alpha.4` кнопки доступны в «Управлении доменами» внутри карточки.
Закрепление относится к точному имени, TLS, IP-семейству и порту. Его можно
изменить или снять. Правило действует и при выключенном пассивном автоподборе;
неподходящие под него соединения продолжают использовать обычные профили.
Закрепление не объявляет метод рабочим: «Есть ответ» по-прежнему требует
наблюдения трафика. В источнике указывается ручной выбор.

Пауза охватывает домен и поддомены; хранится отдельно от общих исключений,
поэтому возобновление не стирает пользовательский список исключений. Она
действует на обработку по имени HTTP/HTTPS/QUIC. У пакетов голоса Discord нет
доступного доменного имени; для голоса сохраняется отдельный общий переключатель.
Приостановленные и закреплённые наблюдения не предлагаются другим сайтам как
кандидаты по опыту. Каталог сохраняет метод, пока он используется закреплением.

Плановый и ручной общий подбор профиля не запускаются при закреплениях его
доменов либо паузе контрольного адреса. Снимите соответствующее ручное правило,
если хотите заново подобрать общий метод профиля.

Автоматические смены ограничены отдельно для домена/TLS/IP/порта. Настройки:
`adaptive_cooldown_seconds` — 10–300 секунд (по умолчанию 30),
`adaptive_max_switches` — 1–20 смен за десять минут (по умолчанию 6).
Первая смена после обычного порога сбоев не задерживается. Последующие смены
откладываются до окончания паузы или десятиминутного окна. Метод сохраняется,
соединения не блокируются самим ограничителем. История объясняет сбой,
источник следующего кандидата и причину отложенной смены. Ручное закрепление
имеет приоритет над автоматическим ограничителем.

Карточка коробки показывает причину отложенной смены и время снятия ограничения.
Если у доменов одного метода разные сроки, отображается диапазон. Истёкшие
ограничения, а также ограничения при ручном закреплении, исключении или
выключенном автоподборе не показываются как действующие. История сохраняет
причину и время прежней задержки. Окончание паузы само по себе не запускает
смену: для неё нужны новые сбои соединений.

Формат кадров `PILOT3` добавляет времена и счётчики ограничения. Старые `PILOT1`
и `PILOT2` читаются без удаления выбранных методов. Объём по-прежнему ограничен
512 записями, 128 записями истории и 512 КиБ на слот. После записи `PILOT3` более старый
контроллер, поддерживающий только прежние форматы, не сможет прочитать этот опыт.

Сброс обучения удаляет только точное имя из обоих слотов, истории и списка
обнаруженных доменов; поддомены не сбрасываются. Ручные правила и другие домены
остаются. На время сброса работающий движок останавливается, данные заменяются
атомарно с сохранением владельца и прав, затем движок запускается вновь. При
ошибке запуска выполняется возврат прежних файлов и попытка восстановления
движка; ошибка восстановления явно сообщается в панели.

## Расширенный набор

Всего 28 встроенных вариантов, включая обычное соединение. К первоначальным
восьми добавлены 20: HostFake с MD5/SEQ/timestamp, комбинации fake + HostFake /
split/disorder, split с SEQ-overlap 1/32/256/681, disorder с overlap 1/32
и fakedsplit с timestamp.
Для `fakedsplit` исправлен формат позиции: этот метод принимает один маркер
`midsld`, а не список маркеров. Используется встроенный TLS-шаблон закреплённого движка. Идеи параметров взяты из
Flowseal/zapret-discord-youtube и avatarDD/zapret-gui; Windows-запускатели,
DLL и сторонние бинарники в приложение не переносятся. Это адаптации семейств,
а не обещание точного воспроизведения чужих пресетов. См. [источники](../THIRD_PARTY.md).

Настоящий парсер `nfqws2 --dry-run` проверяет аргументы всех вариантов и доступ
к Lua-файлам. Он **не исполняет Lua и не доказывает сетевой эффект**. Локально
отдельно исполняются Lua-тесты ротации, сохранения, TLS-групп и детекторов с
моделью пакетов; реальный сетевой эффект проверяется на Keenetic.

## Автоматическая загрузка стратегий

Начиная с `0.1.0-alpha.3` откройте **Настройки → Обновлять каталог стратегий**.
По умолчанию проверка включена: первая попытка через 30 секунд после запуска
свободного контроллера, затем раз в 24 часа. Для немедленной загрузки нажмите
**«Загрузить стратегии сейчас»**, затем запустите подбор нужного сервиса.
При ошибке сети повторить загрузку можно той же кнопкой; рабочий набор сохраняется.

Источник — `catalog/strategies.json` и его `.sig` в ветке `feature/keenetic-pilot`
этого репозитория. Это самостоятельный каталог Pilot в JSON. Текстовые пулы
z2k и динамический движок D2K требуют других модулей/файлов и напрямую не импортируются.
Текущий каталог добавляет 7 вариантов: другие позиции разделения ClientHello
и число повторений ложного пакета. Новые варианты не гарантируют обход у провайдера.

При Public-доступе GitHub дополнительных настроек не нужно. При Private
требуется fine-grained GitHub token с правом **Contents: read** только для
этого репозитория. Введите его **локально в SSH роутера**, не в чате:

```sh
(trap 'stty echo' EXIT HUP INT TERM; stty -echo; /opt/keenetic-pilot/bin/pilot --github-token-stdin)
```

Токен хранится отдельным файлом `github-token` с правами `0600`, не попадает
в API/панель и используется только для HTTPS-запросов к источнику каталога.
После сохранения нажмите «Загрузить стратегии сейчас». Сигнатура каталога
проверяется независимо от наличия токена. Если репозиторий остаётся приватным
без токена, доступен сохранённый набор; новые загрузки получат ошибку доступа.

Защита и применение:

- HTTPS с проверкой сертификата и подпись Ed25519 закреплённым ключом приложения.
- Ограничение размера, срока действия, ревизии и допустимых Lua-действий/параметров.
  Shell, произвольный Lua и загрузка файлов через параметры не допускаются.
- Каждый вариант проходит настоящий `nfqws2 --dry-run` до сохранения.
- Каталог сохраняется в конфигурации и доступен без сети после перезапуска.
- Загрузка не перезапускает движок и не заменяет активную стратегию.
  Для добавления вариантов в автоподбор по трафику сохраните настройки
  (это перезапустит движок) или перезапустите службу.
  Новые варианты проверяются обычным подбором TLS 1.2/1.3 с подтверждением и откатом.
- Выбранные ранее варианты сохраняются, даже если исчезли или изменились в новом
  каталоге. Встроенные стратегии остаются доступны.

## Сопровождение каталога

Измените JSON, увеличьте `revision`, укажите совместимый движок и актуальный
`expires`. Подпишите `python3 scripts/sign-catalog.py`, проверьте
`sh scripts/check.sh` и отправьте JSON вместе с `.sig` в исходную ветку.
Пользователям не нужно обновлять приложение для новых совместимых параметров.
Новые методы, отсутствующие в разрешённой схеме/движке, требуют выпуска приложения.

Закрытый ключ `local/catalog-signing.pem` не попадает в Git или пакеты.
Сохраните его в защищённой резервной копии. Потеря ключа требует выпуска новой
версии приложения с новым доверенным публичным ключом; не заменяйте ключ молча.
`--init-key` применяется только для первоначального создания доверенного ключа.

## Ускорение подбора с alpha.12

При подборе сервиса исходная прямая проба и перебор кандидатов используют
по одной попытке на каждую пару адрес/TLS/IP. Порядок кандидатов: сохранённый
метод, свежий совместимый опыт коробок данного сервиса, общий каталог,
недавние неудачные методы. Учитываются WAN, порт 443, TLS, доступное семейство
IP, возраст опыта и ручные правила. История меняет приоритет, но не исключает
кандидата. «Использовать опыт коробок» отключает этот источник приоритетов.

После успешной предварительной пробы метод повторно применяется с новым
процессом движка и проверяется с исходными числом попыток и таймаутом.
Проверки TLS, сертификатов, HTTP-кода и содержимого сохраняются. Неудачное
подтверждение продолжает поиск, отмена/исчерпание времени восстанавливают
прежнюю конфигурацию. Результат ускоренной пробы сам по себе не сохраняется.

В автоподборе по трафику `adaptive_fast_start` по умолчанию true, включая
загрузку прежних настроек. Между сменами 1→2 и 2→3 одного домена/контекста
в каждом 10-минутном окне применяется пауза min(настроенная, 10 с). Между
3→4 и дальше — настроенная пауза. Счётчики окна и время смены продолжают
сохраняться; перезапуск не даёт заново три быстрые смены. Отключение опции
полностью возвращает настроенную паузу. Лимиты общего процесса и контекста,
два сбоя, закрепления, паузы доменов и исключения действуют как прежде.

Если метод из опыта уже дал сбой этому домену в том же TLS/IP/WAN/порту
за последние 10 минут, он не получает повторного приоритета от других
доменов. Он остаётся в обычном пуле. Смена применяется к следующему новому
подключению; автоматические активные запросы ко всем обнаруженным доменам
