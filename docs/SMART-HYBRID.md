# Smart Hybrid alpha.31 [ChatGPT]

Добавлено 16 лёгких вариантов TLS multisplit/multidisorder на базе уже разрешённых движком действий. Старые ID и порядок сохранены; подписанный каталог не изменён. Это кандидаты, а не доказанные на провайдере методы. QUIC и MTProto без изменений. Реальная производительность зависит от сети и требует проверки.

Geo Routing — отдельная страница с 9 стартовыми доменными группами, обнаружением активных Linux VPN-интерфейсов, явным выбором существующей политики и генерацией команд KeeneticOS 5.2. Никаких shell/NDM вызовов для применения, новых маршрутов по умолчанию, изменений firewall, DNS, AWG или сохранения конфигурации. Предпросмотр не подтверждает, что маршрут установлен. Проверить имя интерфейса и политики в CLI, конфликт имён pilot-geo-*, DNS клиента, доступность туннеля, правила страны сервиса и фактическую маршрутизацию. Область групп стартовая; общие CDN/авторизация и IPv6 требуют отдельного теста. Команды auto reject — намерение не допустить прямого fallback, а не гарантия до проверки на устройстве.

Документация: https://support.keenetic.com/titan/kn-1811/en/24723-latest-development-release.html (NDM-4423).

## alpha.32: Telegram без прокси в приложении

Выберите Telegram в Geo Routing. План содержит доменную группу и 9 IPv4 + 5 IPv6 сетей из https://core.telegram.org/resources/cidr.txt (2026-11-26). Команды привязаны к выбранной политике и туннелю, с auto reject. Это снимок списка, не автоматическое обновление. Проверьте IPv6, наличие туннеля в политике и отсутствие конфликтов. Настройки прокси/Worker убраны из UI; старые данные и серверный API сохранены, прежний экспериментальный режим можно выключить явно. Отключите ранее настроенный прокси в клиенте Telegram. Трафик направляется по IP после ручного применения. P2P-звонки, сторонние CDN и доступность требуют проверки; автоматическое применение и откат не реализованы.
