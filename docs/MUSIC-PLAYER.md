# Pilot Radio (alpha.28)

В верхней панели вместо музыки — интернет-радио. Десять встроенных прямых HTTPS-потоков (Record, SomaFM, Radio Paradise), поиск по жанру, избранное и громкость в локальном хранилище браузера, собственный HTTPS-поток, таймер 15/30/60 минут и стоп с освобождением соединения. Автозапуск, загрузка файлов, прокси, опрос станций и автоматические переподключения отсутствуют. Собственные URL не сохраняются. Доступность потока и декодирование зависят от сети и браузера; сервер Pilot не проверяет вещание.

Источники адресов: https://docs.juniper.bot/music/radio-stations ; https://somafm.com/listen/ ; https://github.com/RASPIAUDIO/MuseRadio-DEMO .

Обзор: чтение адаптивной истории не чаще 12 секунд для одного виджета вместо каждого 4-секундного статуса; сортировка предварительно вычисляет статистику для каждой коробки. Скрытая страница не инициирует эти запросы. Контроль трафика, ключи и подписанный канал обновлений не изменены.
