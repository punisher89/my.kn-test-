# Макет Keenetic Pilot

Самостоятельный интерфейс проекта. Не копия панели z2k или D2K.

```sh
python3 design/serve.py
```

Локальный порт: `9091`. Переключение страниц работает; сохранение настроек,
запуск обхода и сетевые проверки в макете запрещены. Все значения и результаты
из `demo-state.json` демонстрационные; подключения к роутеру нет.

Панель продукта использует те же HTML/CSS/JS, но получает состояние от Go API.
Демонстрационный сервер и его данные не входят в Go-бинарник.

## Состав

- Обзор: состояние сервиса, профили, протоколы и последняя проверка.
- Сервисы и домены: отдельная стратегия для каждого сервиса, домены,
  контрольные адреса и ожидаемый ответ.
- Подбор: прямое соединение → варианты → повторное подтверждение → сохранение
  либо откат. Отдельные результаты TLS 1.2 / 1.3 и IPv4 / IPv6.
- Журнал: события контроллера и движка.
- Настройки: WAN, IPv6, PPE, QUIC, экспериментальный Discord UDP,
  автоматический повторный подбор и исключения.

## Границы прототипа

Проверка TLS 1.2 — не эмуляция ClientHello телевизора webOS. Контрольные HTTP
запросы не подтверждают воспроизведение потока Googlevideo или голос Discord.
Для этих результатов нужны испытания на KN-1811 в сети Ростелеком.
